# 视觉方向 — 汐间 / BETWEEN TIDES

## 设计命题

半透明的数字潮间带：泡沫、星夜、月光与水面的折射。粉色是光，冰蓝是水，玻璃是两者之间的介质。内容是主角，装饰只负责让空间安静下来。

## 取色来源

配色结合 Denia 立绘中的浅粉、珍珠白与冰蓝，以及站点图集里的五张画面（`data/gallery.ts`）。深色主题取星夜与暮色，浅色主题取泡沫与粉白。

| 来源画面 | 取样特征（`scripts/analyse-images.mjs`） | 主题角色 |
| --- | --- | --- |
| 泡沫梦境 BUBBLE DREAM | 平均亮度 175.8，粉 33% / 蓝 50%，主色 #F9F7FB #F9E8F8 #E8D7E9 | 浅色主题基底、Hero 主视觉 |
| 虹彩潮汐 IRIDESCENT TIDE | 平均亮度 174.3，粉 45%，主色 #F9F7F8 #F6E9E7 | 粉色强调、渐变高光 |
| 月下微光 MOONLIT SHADOW | 平均亮度 151.5，粉 36%，主色 #D6C7C9 #85767C | 浅色主题的次级文字与边框 |
| 暮色回声 ECHOES AT DUSK | 平均亮度 103.2，粉 15% / 蓝 34%，主色 #1B2534 #876685 | 深色主题的紫调表面 |
| 深蓝潮汐 DEEP TIDE | 平均亮度 105.3，蓝 76%，主色 #46598A #141939 | 深色主题的蓝调与星点 |

## 语义 token

`styles/tokens.css` 管理界面语义色，Hero 的半透明折射高光在 CSS Module 中定义，深浅两套各自设计，不靠反色：

| token | 深色（星夜） | 浅色（梦境） | 用途 |
| --- | --- | --- | --- |
| --background | #110e1e | #f7f3f8 | 页面底色 |
| --surface / --surface-elevated | #1b162b / #282039 | #ffffff / #ffffff | 卡片与浮层 |
| --glass | rgba(38,29,52,.55) | rgba(255,255,255,.74) | 玻璃面板、导航 |
| --primary / --primary-strong | #f6d5e4 / #efb6d2 | #8f4a6c / #a84e78 | 粉色强调：焦点、当前项、链接 |
| --secondary | #a9d8f0 | #1e6089 | 冰蓝：按钮底、折射、次级强调 |
| --accent | #c25c82 | #b8506f | 极少量标记（按钮图标） |
| --glow-pink / --glow-blue | rgba(244,158,203,.2) / rgba(88,150,215,.22) | 同名浅色版 | 环境光、光晕、泡泡 |

规则：粉色负责"光"，冰蓝负责"水"；同一控件里两者不相邻堆叠。主按钮为柔粉渐变与深色字，冰蓝用于水面和折射；浅色模式采用深玫瑰底与白字。

## 版式与层次

最大宽度 1280px。首页顺序：Hero → 状态/音乐条 → 精选文章 → 项目 → 图集/随记 → Footer。

- Hero：左侧文字，右侧 Denia 透明立绘，背景为粉色星空海面。玻璃光环、倾斜轨道、间歇流星与水面涟漪建立层次。人物鼠标视差 ≤8px，手机端改为上下构图；玻璃名牌与可点击泡泡漂浮在人物前景。
- 玻璃层次：`.navbar.scrolled`、`.now-panel/.music-panel`、Hero 的玻璃名牌和短句卡、`.aside-card`、`.now-strip-item`、`.start-grid a` 都用半透明底 + `backdrop-filter: blur() saturate()` + 顶部 1px 高光，形成"薄片叠起来"的观感。
- 图集：自适应网格（≥1100 约 4 列，1024 三列，768 两列，≤700 一列），固定 `width/height` 避免跳动，原生 dialog 灯箱。
- 文章 740px、17px 中文、1.95 行高，移动端 16px；目录与正文同源。
- 强调手法：标题的第二段用粉→冰蓝渐变裁字（`background-clip: text`），是整站唯一的渐变文字，只在 Hero 与内页页头出现。

## 动效

Framer Motion 0.55 秒淡入、14px 上移；hover -2px；环境光 58 秒缓慢漂移；星星 38 秒明暗；泡泡 9–14 秒漂浮；五次点击泡泡显示本站原创提示 Resonance detected.，4 秒消退；搜索为 Cmd/Ctrl+K 原生 modal dialog；灯箱支持方向键与 Esc，关闭后焦点回到触发按钮。移动端停用视差，reduced-motion 禁用装饰动画。

## 验收

先完成首页再继续内页；实际在 1440 / 1280 / 1024 / 768 / 430 / 390 / 375 / 1920 视口浏览，检查浅色模式、键盘、搜索、音频、灯箱、阅读、加载与构建。`scripts/visual-audit.mjs` 会实测横向溢出、栅格、对比度（深浅两套）、焦点环与 reduced-motion；Lighthouse 分数只有实际测量后才能报告。
