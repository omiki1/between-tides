# Q 版开场动画实现与检查

2026-09-16

沿用 `HomeIntro`、首页挂载位置与 `layout.tsx` 启动脚本；仅替换开场视觉及生命周期。用户修改过的相册、首页、About 等页面保持原有内容。

## 时间顺序

- 资源加载：等待背景、原立绘与 Q 版图像；最多 1.6 秒，失败时继续，不阻塞整站。
- 0.03–0.68 秒：原立绘平滑入场；保留的“伪物 / 弥留”“蚀刻 / 繁彩”按原有节奏分层出现。
- 0.8–1.3 秒：原立绘沿 Y 轴连续翻转，背面成为 Q 版小人；取消中间关键帧的减速及缩放，柔光环同步加快。
- 1.3–4.4 秒：小人从原位开始轻晃，泡泡上升，水面扩散涟漪。翻转层预先准备 transform，柔光环只动画 transform 与 opacity。
- 4.4–5.2 秒：开场向上揭开，进入首页。
- 底部保留 `DENIA · WUTHERING WAVES` 和跳过按钮。

## 交互

每个会话播放一次，版本键 `between-tides.home-intro-seen.v2`。使用 `/?intro=1` 重播，或发送已有的 `between-tides-replay-intro` 事件。按钮或 Escape 随时跳过；减少动态效果的系统设置会直接进入页面。开场期间背景内容设为 inert，结束/跳过/卸载恢复原值，避免键盘误触首页。

## 验证

- 桌面实际观察到翻转后的 Q 版、保留文字、3 张图片加载成功。
- 自动退出、跳过和第二次普通访问：状态均为 seen，inert 残留为 0。
- 390×844 手机布局：无横向溢出，文字未覆盖角色，跳过按钮在视口内。
- 新资源总计 153,740 字节，透明小人有真实 alpha。
- `npm run lint`、`npm run typecheck`、`npm run verify` 与链接检查。
